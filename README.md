# XIAOSHI_Publicity_Group
A Repository of the publicity group of Ningbo Xiaoshi High School
---

### 欢迎来到宁波市效实中学宣传组的文件仓库。
该仓库旨在帮助各位宣传组成员便捷地下载，使用宣传组的各项模板，专属工具和规范文件。
- Applications：存放了常用应用程序和应用程序的下载链接
- Fonts：字体文件
- Photography_Club：摄影社文件
- VOX_Files：效实视界文件
- Xiaoshi_Logo：效实的logo，用于放在视频左上角和海报上等
- 10MBcompressorverticalavail.py：图片压缩程序，压缩到10MB内
- CanvaTeamLink：可画的会员链接
